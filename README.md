# Castle+ Streaming Clone

A responsive streaming portfolio project with live movie data and a polished entertainment interface.

## Features

- TMDB-powered movie data
- Responsive content rows
- Title browsing
- Reusable media components
- Mobile-friendly interface

## Built With

- React
- Vite
- JavaScript
- TMDB API

## Requirements

- Node.js 20 or newer
- npm

## Installation

```bash
git clone https://github.com/Miingo954/castle-plus-clone.git
cd castle-plus-clone
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local URL shown in your terminal.

## Available Scripts

```bash
npm run dev
npm run build
```
